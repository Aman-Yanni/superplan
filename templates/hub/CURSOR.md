# Cursor — add bound repos to the workspace

Cursor does not have Claude's `additionalDirectories`. For this hub to see
product code:

1. **File → Add Folder to Workspace** for each path in `superplan.yml` `repos`.
2. Or open files by absolute path.

Do not copy Superplan skills into `.cursor/skills/` in this hub. Personal skills
live in `~/.cursor/skills`.
